
# Visualizations & Analytical Insights

This directory contains key exploratory data analysis (EDA) plots and statistical test outputs for the **NYC Taxi Revenue Optimization** project.

---

### 1. Payment Preference Overview
Analyzes passenger distribution across different payment methods (Card vs. Cash) to identify overall market preference.

![Overall Payment Preference](Overall%20Payment%20Preference.png)

---

### 2. Fare Amount Distribution by Payment Type
Compares the spread, median, and outliers of fares generated across payment types to observe differences in ticket size.

![Distribution of Fare Amount by Payment Type](Distribution%20of%20Fare%20Amount%20by%20Payment%20Type.png)

---

### 3. Trip Distance Distribution by Payment Type
Evaluates whether passengers taking longer routes tend to prefer cashless transactions compared to short-distance riders.

![Distribution of Trip Distance by Payment Type](Distribution%20of%20Trip%20Distance%20by%20Payment%20Type.png)

---

### 4. Passenger Count Breakdown
Highlights rider group dynamics across payment types to assess if group rides correlate with specific transaction behaviors.

![Passenger Count by Payment Type](Passenger%20Count%20by%20Payment%20Type.png)

---

### 5. Statistical Hypothesis Testing
Validates whether the observed differences in fare amounts and trip metrics between payment types are statistically significant (e.g., T-Test / Mann-Whitney U Test).

![Statistical Hypothesis Testing](Statistical%20Hypothesis%20Testing.png)

---

### Summary Table

| Visualization | Primary Metric | Analytical Focus |
| :--- | :--- | :--- |
| **Payment Preference** | Transaction volume (%) | Adoption rate |
| **Fare Distribution** | Total fare ($) | Revenue spread & outliers |
| **Trip Distance** | Distance (miles) | Journey length correlation |
| **Passenger Count** | Group size | Behavioral segment |
| **Hypothesis Testing** | p-value / test statistic | Statistical validity |
